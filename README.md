# MoneyFlow
**แอพพลิเคชั่นสำหรับบริหารการเงินของคุณ**

version 1.0.3

สร้างด้วย Flutter Framework บน AndroidStudio
โปรเจคแรกสำหรับการศึกษา Flutter 


## Feature หลัก
* **สร้างการเงินที่ดี:** เพิ่มข้อมูลรายรับรายจ่ายทั้งเดือนของคุณแล้วให้แอพแสดงผลในรูปแบบกราฟิก
* **วิเคราะห์ปัญหา:** เช็คข้อมูลของคุณในหน้า "วิเคราะห์" เพื่อดู อัตราออม อัตราการใช้จ่าย เงินสำรองชีพ และ สัดส่วนการเงินของคุณทั้งหมด
* **สำรองข้อมูล:** สามารถสำรองข้อมูล และ นำเข้าข้อมูลได้ กรณี ย้ายเครื่อง
